Use of Search Engines
సెర్చ్ ఇంజిన్ల ఉపయోగం

Search engines help you find information on the web by typing keywords or questions.
సెర్చ్ ఇంజిన్లు కీవర్డ్లు లేదా ప్రశ్నలను టైప్ చేయడం ద్వారా వెబ్‌లో సమాచారాన్ని కనుగొనడంలో సహాయపడతాయి.

Typing a URL
URLని టైప్ చేయడం

A URL (Uniform Resource Locator) is the address of a webpage on the internet.
URL (యూనిఫార్మ్ రిసోర్స్ లొకేటర్) అనేది ఇంటర్నెట్‌లో వెబ్‌పేజీ యొక్క చిరునామా.

Protocol
(https://) – Secure communication between browser and website.
(https://) – బ్రౌజర్ మరియు వెబ్‌సైట్ మధ్య సురక్షిత కమ్యూనికేషన్.
Domain
(www.example.com) – The website's unique name.
(www.example.com) – వెబ్‌సైట్ యొక్క ప్రత్యేక పేరు.
Path
(/page1) – The specific page or resource on the website.
(/page1) – వెబ్‌సైట్‌లోని నిర్దిష్ట పేజీ లేదా వనరు.

Following Links
లింక్‌లను అనుసరించడం

Links are clickable connections that take you from one page to another.
లింక్‌లు క్లిక్ చేయదగిన కనెక్షన్లు, ఇవి మిమ్మల్ని ఒక పేజీ నుండి మరొక పేజీకి తీసుకువెళుతాయి.

Internal Link
Points to another page within the same website.
అదే వెబ్‌సైట్‌లోని మరొక పేజీకి సూచిస్తుంది.
External Link
Takes you to a different website.
వేరే వెబ్‌సైట్‌కు తీసుకువెళుతుంది.
Backlink
A link from another website pointing to yours (important for SEO).
మీ వెబ్‌సైట్‌కి సూచించే ఇతర వెబ్‌సైట్ల నుండి లింక్ (SEO కోసం ముఖ్యమైనది).
Do-Follow Link
Allows search engines to follow and index the link for SEO benefit.
SEO ప్రయోజనం కోసం సెర్చ్ ఇంజిన్లు లింక్‌ను అనుసరించి ఇండెక్స్ చేయడానికి అనుమతిస్తుంది.
No-Follow Link
Tells search engines not to follow or index the link (often used in ads/comments).
సెర్చ్ ఇంజిన్లకు లింక్‌ను అనుసరించవద్దని చెప్పే లింక్ (ప్రకటనలు/వ్యాఖ్యలలో తరచుగా ఉపయోగిస్తారు).
