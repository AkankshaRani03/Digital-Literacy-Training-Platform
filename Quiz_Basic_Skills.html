Basic Computer Skills Quiz

1. Which device displays the output from a computer?
కంప్యూటర్ అవుట్‌పుట్‌ను ప్రదర్శించే పరికరం ఏది?

2. Which of the following is responsible for processing data?
డేటాను ప్రాసెస్ చేయడానికి బాధ్యత వహించే పరికరం ఏది?

3. Which one of these is an example of input device?
ఇవన్నీ లో ఏది ఇన్‌పుట్ పరికరం ఉదాహరణ?

4. What type of software is Windows 10?
Windows 10 ఏ రకమైన సాఫ్ట్‌వేర్?

5. Which software helps detect and remove viruses?
వైరస్‌లను గుర్తించడానికి మరియు తొలగించడానికి సహాయపడే సాఫ్ట్‌వేర్ ఏది?

6. What is MS Word used for?
MS Word ను ఏ కోసం ఉపయోగిస్తారు?

7. Which of these is NOT a hardware component?
ఇవన్నీ లో ఏది హార్డ్‌వేర్ భాగం కాదు?

8. Which application is used to browse the Internet?
ఇంటర్నెట్‌ను బ్రౌజ్ చేయడానికి ఉపయోగించే అనువర్తనం ఏది?

9. What is application software?
అనువర్తన సాఫ్ట్‌వేర్ అంటే ఏమిటి?

10. Which component temporarily stores data being used?
ఉపయోగించబడుతున్న డేటాను తాత్కాలికంగా నిల్వ చేసే భాగం ఏది?
